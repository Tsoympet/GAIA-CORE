# R1 Implementation Scope

R1 implements the Cognitive Kernel as executable runtime governance rather than an architecture-only placeholder.

R1.1 includes goal lifecycle, an execution ledger, step and wall-clock budgets, cooperative cancellation, deterministic verification, runtime integration, operator APIs, and regression tests.

The capability remains `PARTIAL`. Remaining R1 work includes durable persistence, migrations, crash recovery, complete resource metering, approval checkpoints, policy scheduling, event streaming, evidence-ledger integration, and desktop controls.
